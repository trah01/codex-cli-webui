## 环境准备

使用项目首页所列的 [运行环境与启动步骤](../../README.md#环境要求) 安装依赖；集成与端到端测试还需要已登录的 Codex CLI，浏览器测试需要兼容的 Chromium 浏览器。

## 开发与检查

```bash
# 开发模式：监听后端和前端依赖文件的变化
npm run dev

# 静态语法检查
npm run check

# 单元测试
npm run test:unit
```

前端入口是 `public/app.js`，服务启动时生成浏览器 Bundle；开发时修改前端文件后刷新页面。后端入口是 `server/index.ts`。

需要独立构建时运行 `npm run build`，随后可通过 `node dist/server.js` 启动。浏览器、集成和端到端测试的执行入口见 [package.json](../../package.json)，部分测试需要兼容的 Chromium 浏览器或已登录的 Codex 环境。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| `server/` | 服务端入口 `index.ts`、业务模块与终端工作进程 |
| `public/` | 浏览器界面、样式与静态资源 |
| `scripts/` | 开发启动与构建脚本 |
| `tests/` | 单元、集成与浏览器测试 |
| `docs/` | 使用、部署、开发和许可文档 |
| `.github/` | 贡献规范、安全政策与协作模板 |
